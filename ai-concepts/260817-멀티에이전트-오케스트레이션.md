# 멀티에이전트 오케스트레이션 (Multi-Agent Orchestration)

> BACKLOG에 있던 주제, 2026-08-17 학습

## 왜 "멀티"가 필요한가

LLM 에이전트 하나에 모든 걸 시키면:
- **컨텍스트 과부하**: [컨텍스트 엔지니어링](./260807-하네스-컨텍스트엔지니어링.md) 한계에 바로 부딪힘
- **역할 혼재**: 여러 역할을 한 에이전트에 섞으면 각각의 품질이 떨어짐
- **병렬성 부재**: 독립적인 작업을 순서대로만 처리하면 느림

그래서 역할을 나눠 여러 에이전트가 협업하게 만드는 게 멀티에이전트 오케스트레이션.

## 오케스트레이션 패턴

1. **Orchestrator-Worker**: 지휘자 에이전트가 작업을 쪼개 워커들에게 분배, 결과 취합
2. **Sequential Pipeline**: 에이전트 A의 출력이 B의 입력이 되는 순차 흐름
3. **Parallel Fan-out/Fan-in**: 같은 작업을 여러 에이전트가 동시에 독립 수행 후 결과 취합
4. **Debate/Voting**: 같은 질문에 여러 에이전트가 독립적으로 답하게 하고 다수결/심사로 최종 결정 — 한 에이전트의 오판을 다른 에이전트들이 걸러줌
5. **Hierarchical**: 오케스트레이터 아래 또 오케스트레이터가 있는 다단계 구조

## 대표 프레임워크 비교

| 프레임워크 | 특징 |
|---|---|
| **LangGraph** | 에이전트 흐름을 그래프(노드+엣지)로 명시적으로 정의, 상태를 노드 간 전달 — 세밀한 흐름 제어 |
| **CrewAI** | "역할(role) + 목표(goal)"을 가진 에이전트들을 팀(Crew)으로 구성 — 선언적, 비교적 간단 |
| **AutoGen** (MS) | 에이전트끼리 대화(conversation)를 주고받는 방식 — 대화형 협업에 특화 |

## 최소 예제 (의사코드, Orchestrator-Worker)

```python
def orchestrator(task):
    subtasks = plan_llm(task)          # "이 작업을 어떻게 나눌까" LLM이 계획
    results = [worker_agent(t) for t in subtasks]  # 각 서브태스크를 독립 에이전트가 처리
    return synthesize_llm(results)     # 결과 취합도 LLM이 종합
```

## 하네스 / 세션 / 에이전트 용어 정리 (오케스트레이션 이해에 필요한 구분)

- **하네스(Harness)**: 고정된 틀/시스템 자체 (자동차 자체)
- **세션(Session)**: 그 하네스를 한 번 실행시킨 인스턴스 (대화 하나)
- **에이전트(Agent)**: "도구를 써서 스스로 판단하고 행동하는 패턴"을 가리키는 행동 관점의 용어. 세션이 이 패턴대로 동작하면 그 세션을 에이전트라 부름

메인 세션 하나가 서브 에이전트를 여러 개 부르면, **서브 에이전트 하나하나가 각각 별도의 세션(독립 인스턴스)**으로 뜨고, 각자 에이전트로 동작한다. 즉 오케스트레이션 구조에서는 세션 개수만큼 에이전트 개수도 늘어난다:

```
메인 세션 (에이전트 역할: 오케스트레이터)
  ├── 서브 세션1 (에이전트 역할: 워커) — 별도 인스턴스
  ├── 서브 세션2 (에이전트 역할: 워커) — 별도 인스턴스
  └── 서브 세션3 (에이전트 역할: 워커) — 별도 인스턴스
```

## 실무 연결 — Claude Code 자체가 실물 예시

- `Agent(subagent_type: "fork")`: 내 컨텍스트를 통째로 상속한 서브에이전트를 백그라운드로 돌림 → 병렬 작업에 활용
- `Workflow`의 `parallel()`: 여러 에이전트를 동시 실행 후 결과 취합 → **Fan-out/Fan-in**
- `Workflow`의 `pipeline()`: 아이템별로 여러 단계를 거치되 단계 간 배리어 없이 흘려보냄 → **Sequential Pipeline의 최적화 버전**
- "Adversarial verify"(여러 독립 에이전트가 같은 주장을 반박 시도) → **Debate/Voting**
